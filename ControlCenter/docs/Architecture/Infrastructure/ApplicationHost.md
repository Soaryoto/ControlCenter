# ApplicationHost

## Назначение

Отвечает за инициализацию всех сервисов в правильном порядке, регистрации нужных данных для сервисов и сборки DI контейнира

---

## Ответственность

Создание центрального DI контейнера
Настройка запуска React

---

## Использует

Кастомный DI контейнер ServiceContainer

---

## Предоставляет

Нет никаких интерфейсов

---

## Жизненный цикл

Создаёться один раз при запуске программы в классе App

Используеться только в целях передачи нужныйх контейнеров в ViewModels
