# LoggingService

## Назначение

Хранение логов

---

## Ответственность

Сохранение логов до завершения работы приложения
Сохранение логов в отдельной директории
Предоставление список логов

---

## Использует

Нет требуемых сервисов

---

## Предоставляет

Реализует интерфейс ILoggingService - для добавления, редактирования и вывода информации логов
Реализует интерфейс ILoggingServiceReader - для вывода информации логов

---

## Жизненный цикл

Создаётся один раз в ApplicationHost при передачи в DI контейнер ServiceContainer как сервис

Используеться во всех сервисах для логирования
