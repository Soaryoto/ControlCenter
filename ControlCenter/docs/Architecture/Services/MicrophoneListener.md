# MicrophoneListener

## Назначение

Отслеживание и реакция на передачу данных через микрофон

---

## Ответственность

Включает отслеживает передачу данных через микрофон
Отправляет реакцию по условиям по WebSocket данные в React
Отключает отслеживает передачу данных через микрофон


---

## Использует

Для логирования ILoggingService
Для отправки статуса IWebSocketServerService

---

## Предоставляет

Реализует IMicrophoneListener

---

## Жизненный цикл

Создаётся один раз в ApplicationHost при передачи в DI контейнер ServiceContainer как сервис

Используеться только в MainWindowViewModel для запуска и остановки отслеживания микрофона
