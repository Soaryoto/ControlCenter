# ADR-0001. Почему собственный DI-контейнер

Дата: 05.07.2026

## Проблема

Нужно управлять сервисами.

## Рассмотренные варианты

- Microsoft DI
- Autofac
- Собственный контейнер

## Решение

Использовать собственный контейнер.

## Почему

Хочу лучше понять принципы DI и иметь полный контроль над архитектурой.
