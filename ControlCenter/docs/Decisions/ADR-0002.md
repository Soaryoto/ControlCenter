# ADR-0002. Почему Avalonia для UI

Дата: 05.07.2026

## Проблема

Нужен UI для удомного управления

## Рассмотренные варианты

- WPF
- Avalonia

## Решение

Использовать Avalonia так как кросплатформенный

## Почему

Есть вероятность что будет программа запускаться не только на Windows, а так же Avalonia намного больше возможностей
