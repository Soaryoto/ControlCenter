# ADR-0003. Зачем ApplicationHost

Дата: 05.07.2026

## Проблема

Распределение ответсвености классов за функциональность

## Рассмотренные варианты

- Поместить DI контейнер в App.axaml.cs
- Отдельный класс для регулировки существующих сервисов

## Решение

Создать отдельный класс для регулировки существующих сервисов

## Почему

Во первых разграничение ответсвености, а так же "лёгкости" кода для понимания. Отдельный класс что просто ответсвенен за всю регистрацию сервисов
