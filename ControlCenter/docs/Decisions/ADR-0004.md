# ADR-0004. Что использовать для отображения аватара

Дата: 05.07.2026

## Проблема

Малофункциональная программа для отображения аватара

## Рассмотренные варианты

- React страница
- Другие программы для отображения
- OBS

## Решение

Отдельная реализация на React

## Почему

Возможности кастомизации и добавления функциональности при создании отдельной собственной страници используя React
