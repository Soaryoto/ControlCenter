# ADR-0005. Передача данных в React

Дата: 05.07.2026

## Проблема

Нет реакции изменения статуса в зависимости от данных

## Рассмотренные варианты

- WebSocket
- Отдельный файл с Json

## Решение

Выбран был WebSocket

## Почему

Выбран был WebSocket из-за скорости реакции React на изменения, а так же возможности в дальнейшем улучшения навыком использования технологии
