# ADR-0006. Запуск реакт через приложение

Дата: 05.07.2026

## Проблема

Запускаю реакт только с помощью консоли

## Рассмотренные варианты

- Внедрить запуск React в приложение
- Постоянно включенёй React

## Решение

Внедрить запуск React в приложение. Создать отдельный сервис отвечающий за запуск процессов

## Почему

Для лучшего контроля запуска React и сохранения мощностей. А так оставления для дальнейшего развития приложения
