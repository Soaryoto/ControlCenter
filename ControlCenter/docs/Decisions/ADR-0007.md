# ADR-0007. Переключать состояние сервисов

Дата: 12.07.2026

## Проблема

Появляеться проблема при включении всех сервисов сразу, а так же странные проблемы при долгой работе. Нужно как-то нужно иметь отдельный контроль над сервисами

## Рассмотренные варианты

- Одна кнопка на выключение и включение определённого сервиса
- Отдельный контроллер с динамичным списком переключающихся сервисов

## Решение

Лучший вариант сделать динамичный список сервисов для отдельного контроля

## Почему

В скором возможно расширение списка сервисов которые будут переключаться и для этого лучше подойдёт динамичный менеджер выключаемых сервисов
