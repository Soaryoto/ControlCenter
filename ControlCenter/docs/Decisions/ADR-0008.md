# ADR-0008. Сервис по настройкам приложения

Дата: 13.07.2026

## Проблема

Требуетсь корректное определение корневой папки для определения где находиться React приложения для дальнейшей настроки нового сервиса отвечающий за React

## Рассмотренные варианты

- Статичный класс с определителем корневой папки
- Отдельный файл конфигурации
- Сервис для определения настроек

## Решение

Сервис что будет предоставлять многочисленные настройки для всех остальных сервисов и приложения

## Почему

Из-за готовой архитектуры проекта был выбран именно сервисный вид конфигураций
