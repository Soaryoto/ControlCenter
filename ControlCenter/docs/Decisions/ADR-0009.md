# ADR-0008. Определитель корневой директории

Дата: 13.07.2026

## Проблема

Из-за возможности изменения проекта в дальнейшем есть вероятность частой ошибки с директориями

## Рассмотренные варианты

- Конфигурационный файл json
- Специальная директория

## Решение

Отдельная директория для конфигурационных и логирующих возможностей

## Почему

Удобная центральная директория - хранилище для все возможных настроек и логов
